Solução estratégica para consórcios

KhonFácil — Plataforma inteligente de gestão da inadimplência

O KhonFácil é uma solução desenvolvida para apoiar uma agência de consórcios na centralização de dados, análise de inadimplência, priorização de cotas críticas, automação de negociações e suporte à tomada de decisão por meio de BI executivo.

Problema identificado

Contexto operacional que motivou a criação da solução.

Dor do negócio
warning

Alto volume de consorciados inadimplentes e dificuldade de priorizar os casos críticos.

database

Dados dispersos, exigindo tratamento, consolidação e análise para gerar visão confiável.

query_stats

Ausência de um painel decisório integrado para acompanhar cobrança, recuperação e risco.

support_agent

Dependência de atendimento humano para consultas, simulações e negociação de débitos.

Solução proposta

Como o KhonFácil atua sobre o problema.

MVP funcional
monitoring

Dashboard executivo com KPIs, gráficos, filtros, riscos e análise regional.

rule

Priorização de cotas críticas com base em atraso, risco, saldo devedor e status.

smart_toy

Khon Bot para consulta, simulação, autonegociação e pagamento demonstrativo.

workspace_premium

Programa de fidelidade para estimular comportamento adimplente.

Arquitetura da solução

Organização técnica aplicada ao MVP acadêmico.

Web • BI • Mobile

Camada de apresentação

Interface web construída com HTML, CSS e JavaScript, com páginas modulares para autenticação, dashboard, portal administrativo, portal do consorciado, Khon Bot, relatórios, auditoria e configurações.

Camada de dados

O MVP utiliza LocalStorage para simular persistência local no navegador, permitindo demonstrar cadastros, negociações, logs, preferências, pontuação e funcionamento das regras de negócio.

Camada analítica

O dashboard trabalha com dados consolidados para gerar indicadores, análises regionais, comparativos de assessorias, auditoria e insights decisórios.

Camada mobile

O aplicativo mobile é estruturado em React Native/Expo com WebView, consumindo a plataforma publicada em deploy e mantendo consistência visual e funcional.
